About InsightX

InsightX is a premium industry-grade Exploratory Data Analysis (EDA) platform designed to let analysts, students, and engineers audit, clean, visualize, and generate reports on complex datasets instantly.

Architectural Philosophy

The platform is built around a decoupled modular architecture. The Flask core serves as the REST backend orchestrating datasets, users, and reports inside SQLite. Data parsing and analytics modules leverage standard scientific computing packages (Pandas, NumPy, SciPy, Scikit-learn), whereas visualizations are rendered dynamically on the frontend via Plotly.js.

Core Backend Stack
  • Python 3 & Flask web routing
  • SQLite database with Flask-SQLAlchemy
  • Pandas & NumPy for cell transformations
  • SciPy for skewness/kurtosis modeling
User Interface Stack
  • HTML5 & CSS3 custom glassmorphic variables
  • Bootstrap 5 grids & responsive containers
  • Plotly.js for interactive dashboard widgets
  • FontAwesome icons & Google typography

Project Feature Compliance

Authentication System

Secure login/registration utilizing Werkzeug password salting/hashing.

Imputation Toolbox

Impute null variables, cap outliers, and prune duplicates via AJAX actions.

Report Generation Engine

Generate PDF booklets, openpyxl sheets, and PowerPoint slide files on command.

Natural Language Query (NLQ)

Ask questions in English. The engine securely parses and calculates answers.
